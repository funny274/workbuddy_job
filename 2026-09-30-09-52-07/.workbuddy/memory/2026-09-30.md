**版本事实核验**（以官方文档 + Maven Central 为准，纠正了网上大量过时的 1.0 教程）：
- Spring AI **2.0.1**（2026-08-21）为当前稳定版；2.0.0 GA 于 2026-06-12
- 底座：Spring Boot 4.0/4.1 + Spring Framework 7 + Jackson 3 + JSpecify；Java 最低 17，推荐 21/25
- Spring Boot 3.5 已于 2026-06-30 EOL
- 内置 MCP Java SDK 2.0.0，兼容 2025-11-25 MCP 规范
- 维护线：1.1.8 / 1.0.9（均 2026-06-12）

**教程结构**（27 章 + 2 附录，6 周路线）：
- Part 1 基础：ChatClient 流式 API、懒执行语义（call() 不触发执行）、Prompt 模板与分隔符、结构化输出三重保障
- Part 2 核心：ChatMemory（策略/仓储分离）、Advisors（栈式 order 语义、4 个自定义 Advisor 实战）、Tool Calling（@Tool/ToolContext/ToolCallingAdvisor/调用上限/ToolSearch）
- Part 3 RAG：ETL 三件套、VectorStore 与元数据过滤（多租户分区）、模块化 RAG 四阶段、中文分块与 rerank 优化
- Part 4 MCP 与 Agent：协议全景与传输选型、Client/Server 构建（含 Windows STDIO 用 cmd.exe /c 包装的坑）、Agent 分级自主治理
- Part 5 工程化：Micrometer 指标键与高基数规则、Evaluator 评估体系、Prompt Injection 纵深防御、虚拟线程 vs 响应式、1.x→2.0 迁移全清单
- Part 6 面试：50 问 + 综合项目（企业知识库 + Agent 客服）+ 简历包装与自检清单

**关键技术要点沉淀**：
- 2.0 核心变革：工具循环从 ChatModel 内部搬入 Advisor 链，成为递归可组合 Advisor；同一机制驱动工具循环/结构化重试/评估循环
- 2.0 破坏性变更：配置属性扁平化（去掉 `.options`）、Options 严格不可变（copy→mutate、N→n）、移除 internalToolExecutionEnabled、Advisor 全改 builder 构造、模块重命名（advisors-vector-store→vector-store-advisor、tool-search-tool→tool-search-advisor）、MCP 传输 groupId 改 org.springframework.ai
- 2.0.1 修复 7 个 CVE，其中工具解析全局回退（Prompt 注入分发未声明工具）、语义缓存跨租户绕过、Redis 记忆标签注入最值得讲
- 易踩坑：`ChatClient.create(chatModel)` 会绕过自动配置导致可观测性丢失；命令式项目也需引 WebFlux 才能流式；中文分块必须自定义 punctuationMarks；多租户过滤条件必须参数化防注入；缓存 key 必须含租户

**交付方式**：Markdown 文档 + 对话内六周路线图（SVG widget）+ 结果卡片展示
