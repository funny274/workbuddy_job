为什么要「重新」学 Redis

你写了 12 年代码，Redis 一定用过。但面试官在 10 年+ 岗位上的问法，和你日常用 Redis 的方式是两件事：

层级面试官想听到的典型的「不合格回答」
会用（1-3年）set/get、5 种数据类型、能缓存「Redis 就是个缓存」
懂原理（3-5年）单线程/epoll、SDS/跳表、RDB/AOF、过期淘汰「Redis 是单线程所以快」——不问为什么快、瓶颈在哪
能架构（5-8年）主从/哨兵/Cluster 选型、脑裂、槽迁移、跨机房容灾「集群就是分片，扩容加机器」
能治问题（8-10年）热 Key 打爆单分片怎么定位、双写一致性怎么兜底、大 Key 怎么平滑治理「加本地缓存就行」——说不出怎么发现、怎么兜底、怎么回滚
能做 trade-off（10年+ / 专家）在一致性、可用性、成本、复杂度之间做决策，并说清代价「都上 Cluster + Redlock 就完事了」
⚠️ 速成的边界（先说清楚，免得你期待错）

5 天能让你：建立完整的知识地图 + 掌握高频深度答法 + 具备可上手操作的能力。
5 天不能让你：真正拥有「扛过 618 大促」的经验，那是实战沉淀。
本教程的策略是——用真实的线上故障复盘，把别人的实战经验压缩成你的认知。你在面试里讲这些案例，效果远好于背八股。

5 天学习路线图

节奏是「先跑通，再深挖，再架构，再治问题，最后打磨面试表达」。每天建议 6-8 小时。

Day 1会用：环境 + 数据类型 + 客户端
  1. 环境与部署：Docker Compose 一键起「大厂同构」环境（单机 + 主从 + 哨兵 + Cluster + 密码/ACL）
  2. 八大数据结构与场景选型：String/Hash/List/Set/ZSet + Bitmap/HLL/GEO/Stream，每种都有完整案例
  3. 命令行与 Java 客户端实战：redis-cli 高效用法、Jedis/Lettuce 连接池、Pipeline、批量效率实测

产出：本地跑起一套可用的 Redis 环境，能独立完成常见业务建模。

Day 2懂原理：为什么快 + 怎么不丢
  1. 线程模型与 epoll：单线程为什么扛 10 万 QPS、Redis 6.0 多线程改了什么、瓶颈到底在哪
  2. 底层数据结构源码级剖析：SDS、listpack、quicklist、跳表、渐进式 rehash
  3. 过期删除与内存淘汰：惰性 + 定期、8+2 种淘汰策略、LRU 近似实现、LFU 计数器
  4. 持久化：RDB fork/COW、AOF 三策略、Multi-Part AOF、混合持久化选型

产出：能把「Redis 为什么快 / 会不会丢数据」讲成一整套有因果链的答案。

Day 3会架构：高可用与扩展
  1. 主从复制与哨兵：PSYNC 全量/增量、repl_backlog、哨兵选举、脑裂与 min-replicas
  2. Cluster 集群：16384 槽、MOVED/ASK、Gossip、故障转移、8.4 原子槽迁移

产出：能根据业务规模选型，能画出容灾架构并说明故障切换行为。

Day 4会治问题：缓存治理与线上实战
  1. 缓存三大问题与双写一致性：穿透/击穿/雪崩 + Cache Aside / 延时双删 / Canal 方案
  2. 分布式锁与 Lua/Function：SETNX 演进、Redisson 看门狗、Redlock 争议、Lua 原子性
  3. 大 Key / 热 Key 与线上治理：京东 JDHotKey、得物内核改造、B站 HeavyKeeper 三大流派 + 真实故障复盘
  4. Redis 8.x 新特性全景：8.0 → 8.6 逐版本差异、HOTKEYS、LRM 淘汰、FT.HYBRID、Vector Set

产出：能独立排查线上 Redis 抖动，能说清方案代价与兜底。

Day 5会面试：表达与实战答题
  1. Java 生态：Jedis/Lettuce/Redisson/Spring Data Redis 选型与坑
  2. 性能调优与可观测性：慢日志、--latency、INFO 指标、监控告警、内核参数
  3. 场景题实战手册：秒杀、排行榜、延时队列、限流、UV 统计等 12 个大厂真题
  4. 面试八股深度问答：100+ 题，分 4 个深度等级
  5. 生产上线 Checklist 与进度追踪

产出：一套能直接用在面试里的表述，以及一份可落地的生产规范。

💡 一个建议

环境准备（开始前 5 分钟）

本教程的案例默认你有一台能跑 Docker 的机器（Windows / macOS / Linux 均可）。如果你只想快速开始，Day1 会给出三种安装路径。

# 先确认 Docker 可用（Day1 会详细讲）
docker --version
docker compose version

# 网络受限时的备选：直连官方镜像或使用国内源
docker pull redis:8.6
📌 关于版本

本教程以 Redis 8.6（2026-02-10 GA）为主要基线，同时标注 6.x / 7.x 的差异——因为很多公司生产还是 6.x/7.x，面试时能说清版本差异是加分项。
如果你所在公司用的是 Valkey（Redis 7.2.4 分叉）或 KeyDB / Tair，核心原理一致，本教程内容同样适用。
